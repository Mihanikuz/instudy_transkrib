# instudy_transkrib

Сервер автоматической транскрибации лекций для «Моего расписания» ([instudy](https://github.com/Mihanikuz/instudy)).

Демон на GPU-сервере сам забирает из instudy дни с аудио без транскрипта (от самых старых к новым), делит запись на спикеров (pyannote community-1), распознаёт речь (GigaAM v3 e2e RNNT, с пунктуацией) и возвращает в instudy два файла:

- `.vtt` — субтитры с таймкодами и голосами `Спикер N`, для плеера;
- `.txt` — читаемый текст `[ЧЧ:ММ:СС] Спикер N: …` для скачивания и кнопки «Открыть».

Входящих портов нет: сервер работает за NAT и сам ходит в `api.<домен>` по сервисному токену.
