# T-12 · Опрос раз в час и большие исходные дорожки

```
Прочитай CLAUDE.md, docs/architecture.md (разделы «Конфигурация», «Цикл демона»), docs/contract.md, transkrib/config.py, transkrib/daemon.py, transkrib/cli.py, compose.yml, .env.example. В instudy — docs/tasks/BE-23.md (парная задача: исходная аудиодорожка из видео без перекодирования, сжатие после транскрибации). Ты — senior Python-разработчик.

Решение человека (23.10.2026): демон проверяет instudy раз в час; аудио для транскрибации — исходная дорожка из видео, она больше сжатой в 2–4 раза.

Сделай:
1. POLL_INTERVAL_SEC по умолчанию 3600 (config.py, compose.yml, .env.example, docs/architecture.md, README). Это интервал только для простоя (jobs/next → 204): после завершённой работы следующая запрашивается сразу, как сейчас; heartbeat во время работы — по-прежнему HEARTBEAT_SEC (300); повторы при ошибках, 401 и проверка моделей — без изменений.
2. Пауза и места на диске проверяются раз в 60 с независимо от POLL_INTERVAL_SEC (отдельная константа, не настройка): cli resume и освобождение диска срабатывают в течение минуты, а не часа.
3. Сон простоя прерываемый: SIGTERM — как сейчас (выход за секунды); `cli resume` и новая команда `cli poke` («спросить instudy сейчас») будят демон в течение нескольких секунд (файл-флаг в DATA_DIR, демон проверяет его во время сна; без сигналов между контейнерами). cli status показывает «следующий опрос в ЧЧ:ММ».
4. Healthcheck не должен считать демон мёртвым во время часового сна: отметка в state.json обновляется во время сна (как сейчас при heartbeat), HEALTH_MAX_AGE_SEC не меняется.
5. MAX_AUDIO_BYTES по умолчанию 1 ГиБ (1073741824): исходные дорожки 5-часовых лекций — 300 МБ и больше. Свободное место перед скачиванием: не меньше MIN_FREE_GB плюс 3 × audioSizeBytes (аудио + WAV 16 кГц + запас), иначе работа не берётся (pause low_disk), а не падает посреди. Если instudy в BE-23 назовёт другой предел — бери его и опиши в PR.
6. Проверь, что конвейер не зависит от битрейта/частоты входа (ffmpeg приводит к 16 кГц моно) — тест на сгенерированном стерео AAC 44,1 кГц 128 кбит/с.

Критерии приёмки (pytest без GPU и сети):
- по умолчанию poll_interval_sec == 3600, max_audio_bytes == 1 ГиБ;
- 204 → следующий jobs/next через POLL_INTERVAL_SEC; после done → сразу;
- пауза снята во время часового сна → работа взята в течение 60 с (фейковые часы);
- cli poke во время сна → jobs/next в течение нескольких секунд;
- SIGTERM во время сна → выход < 5 с;
- health во время сна — 0 (отметка свежая);
- мало места под 3 × audioSizeBytes → работа не берётся, статус paused (low_disk);
- стерео 44,1 кГц на входе → WAV 16 кГц моно, конвейер проходит.
```
