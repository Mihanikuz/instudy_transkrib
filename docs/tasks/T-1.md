# T-1 · Каркас, CI, конфиг, логи

```
Прочитай CLAUDE.md, docs/architecture.md, docs/decisions/001-scope.md. Ты — senior Python-разработчик. Репозиторий Mihanikuz/instudy_transkrib пустой, кроме документов. Задача — каркас проекта, на который лягут остальные задачи.

Сделай:
1. pyproject.toml (пакет transkrib, Python 3.12, ruff — правила как в instudy: E, F, W, I, B, UP, S, line-length 120; pytest с маркером gpu, пропускаемым по умолчанию). requirements-dev.txt — только то, что нужно тестам и линтеру (pytest, ruff, httpx, pydantic-settings, numpy), версии зафиксированы. GPU-зависимости сюда не входят — их добавит T-2.
2. Проверь совместимость Python 3.12 с колёсами torch==2.8.0+cu128 / torchaudio, pyannote.audio 4.x и GigaAM (по метаданным пакетов, без установки CUDA): если 3.12 не подходит — переходи на 3.11 и опиши причину в PR.
3. transkrib/config.py — pydantic-settings, все переменные из таблицы «Конфигурация» docs/architecture.md с умолчаниями и проверками: INSTUDY_API_URL только https://, SERVICE_TOKEN обязателен для демона (но не для cli run-file / models-*), положительные интервалы. SERVICE_TOKEN — SecretStr.
4. transkrib/log.py — JSON-логи в stdout (время UTC, уровень, логгер, сообщение, поля extra). Фильтр секретов: маскирует значение SERVICE_TOKEN, «Bearer <…>», query-строки ссылок на /api/service/audio (всё после «?»), параметры sig= и exp= — в сообщении, аргументах, extra и тексте исключений.
5. Заглушки точек входа: python -m transkrib (печатает версию и выходит), python -m transkrib.cli с подкомандой version.
6. Dockerfile и compose.yml — заглушки с комментариями «наполнит T-7» (чтобы горячие файлы существовали); .env.example со всеми переменными без значений секретов; .gitignore (data/, models/, .env, аудио, *.vtt/*.txt вне tests/fixtures), .dockerignore.
7. CI: .github/workflows/ci.yml — ruff check, ruff format --check, pytest на ubuntu-latest с Python 3.12 и установленным ffmpeg.

Критерии приёмки (pytest):
- конфиг с http:// в INSTUDY_API_URL не создаётся; без SERVICE_TOKEN демонская конфигурация падает с понятной ошибкой, а конфигурация CLI — нет;
- repr/str конфигурации и model_dump не содержат токена;
- лог-фильтр маскирует токен в сообщении, в args, в extra и в тексте исключения (logger.exception); маскирует query у https://api.example/api/service/audio/5?exp=1&sig=abc;
- python -m transkrib и python -m transkrib.cli version завершаются с кодом 0;
- CI зелёный.
```
